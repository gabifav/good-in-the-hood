🖨️ Printing tips & alignment
  1. First time: tap Test on plain paper, print it, then hold it against a label sheet up to a window. The boxes should line up with the labels.
  2. If they're a little off, nudge them below (in millimetres) and test again. Your nudge is remembered on this phone.
  3. When printing: choose the Kyocera, paper A4, scale 100% / Actual size (not "Fit to page").
  4. Put label sheets in the bypass (side) tray and set the paper type to Labels if asked.
